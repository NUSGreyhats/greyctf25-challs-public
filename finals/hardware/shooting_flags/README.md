# Solution

On testing its a rather tedious challenge LMAO. too bad I suffered through it so they have too. 
1. Figure out order of the buttons through the 1st shooting pattern
2. Figure out pressing button
2. comment out the lazer in the badge code so that it doesnt affect reading of the flag
3. read the flags from the LEDs
4. bitshift and ascii to flag
